15. AI / LLM Integration ⭐

This is where your system can become much more useful than a traditional ticketing application.

However, I recommend implementing AI after the core ticketing system works properly.

Initially, don't allow the AI to automatically close tickets or make production changes.

User enters issue
       ↓
AI analyzes issue
       ↓
Search previous resolved tickets/
knowledge articles
       ↓
Generate suggested solution
       ↓
Display:
"Suggested Resolution"
       ↓
User tries solution
     ↙     ↘
 Worked    Didn't Work
   ↓           ↓
Resolved   Create/Continue Ticket

User raises:

XIRR report CSV columns are getting shifted when downloading the report.

Suggested Solution

A similar issue was previously reported.

Possible Cause:
City names containing commas may cause CSV fields
to shift when values are not properly escaped.

Previous Resolution:
The CSV generation logic was updated to correctly
handle values containing commas.

Was this helpful?

[Yes - Issue Resolved] [No - Continue Ticket]

AI architecture I recommend

Eventually you can build RAG (Retrieval-Augmented Generation) around your resolved tickets and approved knowledge articles.
